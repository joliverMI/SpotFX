Getting a Last.fm API Key
  1. Go to last.fm/api/account/create
  2. Sign in or create a free Last.fm account if you don't have one
  3. Fill in the form:
    • Application name — anything you like, e.g. SpotFX
    • Application description — e.g. Genre lookup for music lighting
    • Callback URL — leave blank
    • Application homepage — leave blank
  4. Click Submit
  5. You'll see your new API key on the next page — copy it
  6. Paste it into the Last.fm API Key field in SpotFX settings and save
The API key is free and rate-limited to 5 req/s — well within SpotFX's usage. Your username is optional; SpotFX only uses it for future scrobbling features.
