# Sauron — offline evidence

Rendered by `scripts/render_sauron.py` (2026-10-10) on the real render
pipeline (`fx.headless`, audio silenced, a fake clock) onto the crystal's
real 976 cells — not his room. One scripted song drives every tile the
same way and with the same seed, so the eye looks at the same place in
every tile: 120 BPM ordinary hits, big hits at 1.75 / 4.25 / 6.25 s that
dart the gaze, a bass swell 2.5-4.0 s (the flames lengthen), and
`sauron_surge` pokes at 3.4 s (full) and 5.8 s (0.7).

- `sauron_sets.gif` — the built effect (every setting at its default,
  `palette_sort` auto) on six of his colour sets: Mid - Fire, Hype 1,
  Mid - Ice, Puerto Rico Red, Mid - Bright Purple, Mid - Blush.
- `sauron_hype1.gif` — Hype 1 under each `palette_sort` choice (auto
  resolves to warm for a rainbow set, so those two tiles match).
- `sauron_moments.png` — frozen moments (rest, a big hit, full bass, a
  surge) for Mid - Fire, Hype 1 and Mid - Ice.

Every number is a first guess pending his live tuning session.

These show the effect as first built. Tune-up 1 (2026-10-11) changed what
`auto` does for a rainbow set (radial, no longer warm), the slit's minimum
width and the perimeter ring — see `docs/evidence/sauron-tuneup-1/`.
